# Locally measured evidence

Linux GCC 14.2, Release/O3. Synthetic audio generated by `stereo_tests`; source belongs to this repository, no external recordings. These are test signals, not a musical listening evaluation.

- `mono-before.wav`: 4 s, 48 kHz stereo PCM16, identical channels.
- `mono-stereoize-matched.wav`: same input through actual StereoImager, Stereoize=0.7 and widths=1; gain adjusted by integrated LUFS difference (about -0.22 dB). No downstream modules. Check stereo and mono playback.
- `metrics.csv`: three rates, four stimulus types; raw output peak/LUFS and LUFS-matched delta. Legacy width=2 versus new width=1 + Stereoize=0.7 are diagnostic settings. Anti-phase bass has effectively zero Mid: S/M ratios are enormous and not meaningful as a musical width score.
- Full mono/narrow/conventional stereo WAV pairs and `bands.csv` can be generated with `stereo_tests evidence`; Windows CI publishes them separately.

Legacy regression comparison: compiled baseline `66926e0` StereoImager and current code with the same deterministic variable-width/balance/mono-bass/solo/Delta sequence, at 44.1/48/96 kHz, 500 x 257 samples per rate. Binary outputs identical with Stereoize zero (SHA256 `3792f65c0b11ff9dba73e1664e6aedf4421ed60091bc0b328d09616be9628a04`). This is a local GCC comparison, not a cross-compiler bit-exact promise.

Provisional CPU probe, 2000 x 257 samples, stereo imager only, including input sine generation. Concurrent JUCE compilation makes these wall-clock values noisy; they establish neither a deadline guarantee nor a reliable overhead percentage:

| Rate | Baseline seconds | Stereoize=0.7 seconds | New audio/wall ratio |
|---|---:|---:|---:|
| 44100 | 0.281307 | 0.244211 | 47.7 |
| 48000 | 0.208624 | 0.271162 | 39.5 |
| 96000 | 0.343735 | 0.281868 | 19.0 |

Reproduce current probe with `stereo_benchmark`; compare baseline by compiling `tests/StereoBenchmark.cpp` against baseline headers without defining `STEREOIZE`. No new dynamic storage is added to StereoImager. Whole-plugin CPU/RAM and realtime host stress remain pending.
