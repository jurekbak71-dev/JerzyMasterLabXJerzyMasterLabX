# Manrope

Source: https://github.com/google/fonts/tree/main/ofl/manrope
Copyright 2018 The Manrope Project Authors. SIL Open Font License 1.1, included in OFL-Manrope.txt.

Manrope.ttf is the weight-400 static instance of the upstream variable font, generated with fontTools.varLib.instancer. Embedded in the plugin to keep typography consistent without requiring a system installation. No network or font loading in the audio callback.
